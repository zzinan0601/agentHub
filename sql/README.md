# sql — 테이블 생성 스크립트

**코어는 기동할 때 테이블을 스스로 만든다.** 그래서 평소에는 이 폴더를 쓸 일이 없다.
DBA 가 미리 검토하고 직접 만들어야 하는 곳 — 폐쇄망 같은 — 을 위한 것이다.

두 길 중 하나만 고르면 된다. 어느 쪽이든 결과는 같다.

| | 언제 |
| --- | --- |
| **코어가 만들게 둔다** | 개발 중, DB 권한이 넉넉할 때. 아무것도 안 해도 된다 |
| **이 스크립트로 만든다** | DDL 을 미리 검토해야 하거나, 앱 계정에 `CREATE TABLE` 권한을 주지 않을 때 |

## 실행 순서

```bash
psql -U postgres -c "CREATE DATABASE agenthub;"
```

```bash
psql -U postgres -d agenthub -f sql/01_schema.sql
```

```bash
psql -U postgres -d agenthub -f sql/02_seed.sql
```

```bash
psql -U postgres -d agenthub -f sql/03_check.sql
```

| 파일 | 하는 일 | 꼭 필요한가 |
| --- | --- | --- |
| `01_schema.sql` | 테이블 7개 + 인덱스 8개 | 코어가 만들게 두면 불필요 |
| `02_seed.sql` | **관리자 계정 미리 만들기** | 선택. 아래 참고 |
| `03_check.sql` | 제대로 만들어졌는지 확인 | 확인용 |

`01_schema.sql` 은 여러 번 돌려도 안전하다(`IF NOT EXISTS`). 이미 쓰던 DB 에 그대로
돌려도 된다.

## 기준 데이터가 왜 이것뿐인가

이 앱에는 코드표나 기준정보 테이블이 없다. **DB 에는 사람이 만든 것만 쌓인다.**

| 무엇 | 어디에 있나 |
| --- | --- |
| 부를 수 있는 에이전트 목록 | `registry.yaml` (파일) |
| 워크플로우 | `core/workflows/*.yaml` (파일) |
| 라우팅·통합 규칙 | `core/prompts/*.md` (파일) |
| 모델명·주소·임계값 | `.env` |
| 사용자·대화·호출 기록 | **DB** |

그래서 `02_seed.sql` 이 하는 일은 하나다 — **관리자 계정을 먼저 잡아두는 것.**
앱은 "가장 먼저 로그인한 사람"을 자동으로 관리자로 만들기 때문에, 그냥 열어두면
아무나 먼저 들어온 사람이 관리자가 된다. 의도한 사람이 관리자가 되게 하려면
서비스를 열기 전에 이 스크립트를 돌린다.

> `username` 은 반드시 **소문자**로 넣는다. 앱이 로그인할 때 이름을 소문자로 바꿔
> 대조하므로, 대문자로 넣어두면 같은 이름으로 들어와도 못 찾고 계정이 하나 더 생긴다.
> 한글 이름은 대소문자가 없으니 그대로 쓰면 된다.

## 모델을 고쳤다면

`core/models.py` 를 고치면 이 SQL 도 같이 고쳐야 한다. 손으로 옮겨 적으면 언젠가
어긋나고, 어긋난 것은 반입한 뒤에야 드러난다. 모델에서 직접 뽑아 대조한다.

```bash
python scripts/dump_schema.py
```
